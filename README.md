# EzLandlord: Smart Property Management System  

A modern **Landlord Tracking System** built with the **MERN Stack**, designed to simplify rental transactions, tenant–landlord interactions, and property management.  

## 🚀 Features  
- **User Authentication** – Secure signup/login for landlords and tenants.  
- **Payment Tracking** – Monitor rent payments and due dates seamlessly.  
- **Digital Lease Signing** – Replace paperwork with e-signature capabilities.  
- **Maintenance Logging** – Tenants can submit requests with photo attachments.  
- **Financial Analytics** – Gain insights into rental income and expenses.  
- **Built-in Chat** – Real-time communication between landlords and tenants.  
- **Database Management** – Robust storage and retrieval for properties, tenants, and transactions.  

## 🛠️ Tech Stack  
- **Frontend**: React.js (with Hooks & Context API for state management)  
- **Backend**: Node.js + Express.js (RESTful APIs)  
- **Database**: MongoDB (Mongoose ODM)  
- **Authentication**: JWT-based authentication and authorization  
- **Deployment**: (Optional) Heroku / Vercel / AWS / Render
